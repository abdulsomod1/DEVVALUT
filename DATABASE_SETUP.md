# Supabase Database Setup for DEV VAULT

## Table Creation (Run in Supabase SQL Editor)

Copy and paste the following SQL into your Supabase Dashboard → SQL Editor → New Query:

```sql
-- Create applications table matching form data
CREATE TABLE IF NOT EXISTS public.applications (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    created_at TIMESTAMPTZ DEFAULT NOW(),
    full_name TEXT NOT NULL,
    email TEXT NOT NULL,
    phone TEXT NOT NULL,
    country TEXT NOT NULL,
    experience_level TEXT NOT NULL,
    interests TEXT[],  -- Array: [\"HTML & CSS\", \"JavaScript\", ...]
    message TEXT,
    status TEXT DEFAULT 'pending'  -- 'pending', 'contacted', 'enrolled', etc.
);

-- Enable Row Level Security
ALTER TABLE public.applications ENABLE ROW LEVEL SECURITY;

-- Allow public form submissions (anon users)
CREATE POLICY \"Public applications insert\" ON public.applications
    FOR INSERT TO anon WITH CHECK (true);

-- Performance indexes
CREATE INDEX idx_applications_email ON public.applications(email);
CREATE INDEX idx_applications_phone ON public.applications(phone);
CREATE INDEX idx_applications_status ON public.applications(status);
```

## Steps:
1. Go to [Supabase Dashboard](https://supabase.com/dashboard)
2. Select your project: `lxgzhvgsfntstpokmfiw`
3. Navigate to **SQL Editor** → **New Query**
4. Paste SQL above → **RUN**
5. Verify table in **Table Editor** → `applications`

## Expected Columns:
| Column | Type | Description |
|--------|------|-------------|
| id | bigint | Auto-generated ID |
| created_at | timestamptz | Submission timestamp |

| country | text | User country |
| experience_level | text | 'Beginner', 'Intermediate', 'Advanced' |
